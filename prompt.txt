  pulseSpeed: random 0.004 to 0.012

Animation loop with requestAnimationFrame:
  ctx.clearRect(0, 0, canvas.width, canvas.height)
  For each particle:
    opacity pulses: particle.opacity + Math.sin(tick * particle.pulseSpeed + particle.pulseOffset) * 0.12
    ctx.beginPath()
    ctx.arc(particle.x, particle.y, particle.size, 0, Math.PI * 2)
    ctx.fillStyle = particle.color with pulsed opacity (use rgba parsing or convert hex)
    ctx.fill()
    Update x += speedX, y += speedY
    Wrap around edges (if x < 0 → x = width, etc.)
  
  tick increments each frame.
  Cancel on cleanup.
